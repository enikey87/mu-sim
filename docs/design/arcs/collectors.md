## Другие финалы

### «Стажёр-коллектор»

Случается, когда игрок нагрубил шесть раз (`when: [gte(count.rude, 6)]`).

**Коллекторы «Деньги-Ара»:** «Мы прослушали ваш разговор с Аликом. Профессионально. Приходите к нам. Стажировка — три чая.»

**Система:** «Вам предложена должность: стажёр-коллектор «Деньги-Ара». Оплата: процент.»

**Как там потом:**

- «Стажировка идёт. Чай наливают, долги слушают. Тебя хвалят.»
- «Меня уже взыскивают по-настоящему. Ты научился быстро.»

**Эпилог** (`ENDGAME_ARCH`, `endgame.ts`) читает выбор игрока, а не значение финала: stored `finale.collectors = 'intern'` пишется до оффера (#1056), поэтому строк стало три —

- «Коллекторы взяли тебя на стажировку. Учат взыскивать с меня профессионально — три чая за смену.» — только после строки согласия (`intern.accepted`: первая и третья кнопки пула);
- «Коллекторы звали тебя в стажёры — ты отказался. Взыскивать с меня будешь по старинке, без чая.» — после отказа (`intern.declined`);
- «Коллекторы предлагали тебе стажировку: три чая за смену. Согласия в деле нет — чай пока не наливают.» — если окно оффера истекло без ответа (`collectors.internAt` ответом не погашен): молчание не выдаётся ни за согласие, ни за отказ.
