## Другие финалы

### «Стажёр-коллектор»

Случается, когда игрок нагрубил шесть раз (`when: [gte(count.rude, 6)]`).

**Коллекторы «Деньги-Ара»:** «Мы прослушали ваш разговор с Аликом. Профессионально. Приходите к нам. Стажировка — три чая.»

**Система:** «Вам предложена должность: стажёр-коллектор «Деньги-Ара». Оплата: процент.»

**Как там потом** — по выбору игрока, а не по факту финала (#1381):

- стажировка принята (`internAccepted`): «Стажировка идёт. Чай наливают, долги слушают. Тебя хвалят.»; «С меня уже взыскивают по-настоящему. Быстро ты научился.»
- предложение без ответа (молчание окна): «Стажировка лежит на столе. Чай — после согласия, брат: раньше не нальют.»
- отказ (`internDeclined`): «Стажировки не будет. Чай без тебя допили, долг твой — с тобой.»
