# Концовки: одно условие

> **Статус:** реализовано · обсуждение: чат 2026-10-14 · задачи: #713, #714, #715, #716, #717

## Идея

Игрок доходит до концовки через один понятный факт партии, а не через стопку условий, разделённых сотнями дней. «Настоящие деньги» — вежливость плюс суд. «Честные деньги» — заказчик заплатил. «Не тебе» — сериал Размика закончился. Каждая концовка объясняется одной фразой: «сделай X — получишь Y».

## Зачем

У концовок два слоя условий (концовка требует частный финал, финал — ачивку) и конъюнкции до четырёх условий («Настоящие деньги»: святость + поимки + суд + квесты). Итог — почти любая партия заканчивается исходом-заглушкой «Пятьдесят рублей» (`default`, пустое условие): 6 из 7 исходов Дня выплаты игрок не видел ни разу. Шпаргалка `ENDINGS.md` это показала; чиним механику, а не описание.

## Как играется

Игрок ничего нового не делает — расширяются двери в уже существующие концовки. Порядок исходов Дня выплаты сохраняется, но держится **бонусами специфичности, а не числом условий**: `real` (4) > `lavash` (3) > `coins` (2) > `niva`/`strasbourg`/`notyou` (1) > `default` (0). У финалов Самвела так же: «Жених» (3) побеждает «Тамаду» (2), когда выполнены оба.

## Факты мира

Новых ключей и говорящих нет: правки читают уже существующие факты (`ach.*`, счётчики, `finale.*`). Убранные условия:

| Что | Было (`main`) | Стало |
|---|---|---|
| 💸 исход `real` (`src/content/rules/payday.ts:147`) | `saint` + `caught≥3` + `court` + `quests≥5` | `saint` + `court`, bonus 2 |
| 🫓 исход `lavash` (там же :150) | поимка + `crypto.hodl` | только `crypto.hodl`, bonus 2 |
| 🏗️ исход `notyou` (там же :154) | `exists(finale.razmik)` + `rude≥8` | только `exists(finale.razmik)` |
| 🏗️ концовка `alik` (`src/content/finales.ts:244`) | `finale.garik='cutter'` + `ach.fence` | только `finale.garik='cutter'` |
| 🐏 концовка `ram` (там же :239) | `finale.boris='toyou'` + `items≥2` | только `finale.boris='toyou'` |
| 🏆 концовка `honest` (там же :249) | 3 финала (boris + grant + niva) | только `finale.grant='ally'` |
| 💍 финал `groom` (там же :71) | `saint` + `rude≤0` | только `saint`, bonus 1 |
| 🗡️ `Rude_Vendetta` (`src/content/rules/rude.ts:134`) | `rude≥25` + `HEAT≥5` + `sorry≤0` | `rude≥15` + `sorry≤0` |

Механика приоритета «Жениха»: генератор правил финалов (`src/content/rules/finales.ts:11`) не умеет `bonus` — расширить интерфейс `Finale` (`src/content/finales.ts:10`) полем `bonus` и прокинуть в генератор.

Тексты переписываются по фактам (убранные условия больше не называются): экран и реплики `real` («ловил на лжи… квесты» → вежливость и суд), реплики и экран `honest` («Борис, Грант и „Нива“» → Грант). Тексты предлагают задачи, финальное слово за автором в ревью.

## Ограничения

Не трогаем: `default` (низ лестницы — у партии без стиля должен быть исход), «Параллельную вселенную» (время — её смысл, эндгейм), day-гейт ~300 у сюжетных (концовка — развязка), состав 14 концовок и их id — досье, ачивки `end_*`, аналитика не мигрируют.

## MVP

1. Payday-исходы: `real`, `lavash`, `notyou` — условия и бонусы иерархии; тексты `real`.
2. Сюжетные: `alik`, `ram`, `honest` — условия; тексты `honest`.
3. Финал `groom`: только `saint` + приоритет над `tamada` (поле `bonus` у финалов).
4. `Rude_Vendetta`: порог 15, снять HEAT.
5. Документация: `ENDINGS.md`, `DESIGN.md` — новые условия.

## Реализация против концепта

Реализовано MVP-1–4 (#713, #714, #715, #716); расхождений с таблицей «Факты мира» нет. Дополнения против исходного замысла:

- сумма «Честных денег» не захардкожена в тексте-тесте, а выведена из факта финала «Союзник» (`fx.pay` → `1 000 ₽`) — текст концовки привязан к тому, что Грант реально платит;
- иерархия исходов Дня выплаты держится бонусами специфичности с комментарием-лестницей прямо в `rules/payday.ts`;
- формулировки текстов `real`/`honest` — авторские (правка оператора в #714), не первоначальные из задач.
