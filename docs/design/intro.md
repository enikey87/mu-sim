# Интро: экран блокировки

> **Статус:** согласовано · обсуждение: чат с Claude, 2026-09-24 · задачи: см. issues с меткой `task`, ссылающиеся на документ · макет: [`intro-mockup.html`](intro-mockup.html) (открыть в браузере)

## Идея

Каждая новая партия начинается не с чата, а с экрана блокировки телефона. Приходит уведомление от Алика с обещанием из завязки партии, игрок отвечает. Дата начинает листаться, сверху сыплются уведомления: «Завтра всё будет», стикер «🏗️», «В понедельник, какой — не скажу», списания из банка. Счётчик «Дней после сдачи» бежит до 184, на фоне — «Мууу». Потом уведомления гаснут, крупно выходит строка завязки («…прошло 184 дня. Пятниц было двадцать шесть…»), за ней титул «Алик, где деньги?». Экран сам уезжает вверх и открывает чат.

## Зачем

- Сейчас партия открывается сразу в чате: пролог из трёх строк легко пролистать, и главная мысль — «ты ждёшь полгода, обещания копятся» — проходит мимо.
- Интро показывает правила без объяснений: обещания копятся, календарь бежит, банк напоминает о деньгах, корова мычит.
- Это тот же телефон, что и вся игра: нового мира и стиля не нужно.

## Как играется

| Время | Что на экране |
|---|---|
| до старта | Только на первом запуске: экран блокировки с датой сдачи и «Коснитесь, чтобы начать». Касание разрешает браузеру звук. После «Начать заново» анимация идёт сразу: касание уже было — кнопка. |
| 0,3 с | Уведомление «Алик: …» — обещание из завязки партии. Следом «Вы: …» — ответ из завязки. |
| 1,8–6 с | Дата листается, счётчик «Дней после сдачи» бежит до 184. Сыплются 5–6 уведомлений: обещания, стикер, банк. |
| 5 с | «Мууууу» — звук и надпись. |
| 6,3–9,3 с | Уведомления гаснут. Крупно, одна на экране — строка завязки. Держится 3 секунды. |
| 9,3–11,8 с | Строка гаснет — титул «Алик, где деньги?», 2,5 секунды. |
| 11,8 с | Экран сам уезжает вверх, под ним чат с тем же прологом — игра началась. |

- **Когда:** на каждой новой партии — первый запуск и «Начать заново». Перезагрузка страницы посреди партии интро не показывает.
- **Касание в любой момент интро** — сразу свайп в чат.
- Из досье интро повторно не открывается.

Ритм и тон — в макете [`intro-mockup.html`](intro-mockup.html). Это набросок, не код игры.

## Факты мира

- Завязка партии (`STARTS` в `content/quests.ts`, выбор в `engine/game.ts`) выбирается **до** интро, и интро показывает именно её. Первое уведомление — первое сообщение Алика в чате, «Вы: …» — ответ игрока, строка завязки — системная строка в чате. Иначе в интро «деньги в пятницу», а в чате «завтра, край — послезавтра».
- «Интро показано» — отметка в сохранении новой партии: перезагрузка его не повторяет, «Начать заново» создаёт новую партию, и интро идёт снова.
- Число дней и дата — из состояния новой партии, а не текстом.
- Промежуточные уведомления — из существующих пулов и без имён персонажей, которых игрок ещё не встречал.

## Ограничения

- Около 12 секунд от старта до чата, в конце экран уезжает сам. Строка завязки и титул держатся, пока их можно прочитать, и каждый — один на экране.
- `prefers-reduced-motion`: без полёта уведомлений и листания — три фазы подряд (обещание → строка завязки → титул), без наложений, потом чат.
- Только CSS и существующие элементы интерфейса: без картинок, шрифтов и библиотек анимации.
- Тесты и бот стартуют без интро: e2e, `npm run playtest` и `scripts/playtest-tech.mjs` не должны ждать анимацию.
- Звук — только после касания (правило браузера) и только если звук в игре включён. «Мууу» — тот же звук, что в игре (его улучшение — #161).
- Интро не меняет ни одного факта партии, кроме отметки «показано».

## MVP

1. Экран блокировки на каждой новой партии; на первом запуске — «Коснитесь, чтобы начать».
2. Обещание завязки и ответ игрока, 5–6 уведомлений из пулов, листающаяся дата и счётчик до 184, «Мууу».
3. Строка завязки и титул «Алик, где деньги?» — крупно, по одному, читаемо; автосвайп в чат; касание — сразу в чат.
4. Статичная версия для `prefers-reduced-motion`, запуск без интро для тестов и бота.

## После MVP

- Вибрация на уведомлениях.
