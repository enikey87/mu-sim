# Пикабу: сценарий нарезки (#1238)

Пять моментов вместо записи GIF: оператор снимает кадры из игры, а не придумывает раскадровку.
Все координаты — из одной партии: **сид 296117, 300 ходов**, код `075628f` (main на 2026-10-22),
расшифровка — плейтест-раунд 113 (`docs/PLAYTEST_ISSUES.md`). Машиночитаемый список координат —
[pikabu-moments.json](pikabu-moments.json), проверка — `node scripts/marketing-moments.mjs`.

Сид — координата **проверки**: бот воспроизводит партию буквально, поэтому «строка 1533» — это адрес, а
не воспоминание. В браузере сид не выставляется, поэтому кадр ловится по точной строке (ориентиры
ниже). Снимать можно и на другой партии — тогда координаты в этом файле надо обновить, иначе следующая
проверка справедливо покраснеет.

Что показать: лестницу «К выплате» до 50 ₽ и саму великую отмазку — она собрана из событий этой же

исходов Дня выплаты не показываем.

## Как это снимать

1. Открыть https://enikey87.github.io/mu-sim/?fast&nointro (или локальный `npm run dev` с теми же
   параметрами) в мобильном окне 390×844: пост читают с телефона, кадр тоже.
2. Играть репликами, которые ведут к моменту:
   - **Нуне** — её арка начинается в первые дни (≈27 сентября по календарю партии): ждать её дебют
     или спросить про деньги в её окне;
   - **фото-баран** — событие приходит само в линии с крышей/козой (в партии 296117 — 3 ноября);
   - **клятва** — обычная отмазка; ловить в блоке, где Алик обещает «на днях»;
   - **«Мууууу»** — 7 % на сообщение (15 % после 50-го, в пятницу чаще); на кадре достаточно любого
     блока с этим вариантом;
   - **День выплаты** — после дедлайна 430 дней; `?fast` ускоряет паузы, но не календарь: нужно
     ~150–200 ответов. Если оператор не хочет играть столько, гифку можно собрать из двух скриншотов
     (лестница «К выплате» + перевод).
3. Снимать без курсора и без панели `?debug`; системные строки и варианты должны быть читаемы, шрифт
   не мельче, чем в игре.

## Проверка координат

```sh
node scripts/marketing-moments.mjs
```

Инструмент переигрывает сид 296117 ботом (300 ходов) и сверяет каждую строку из манифеста: номер
строки и текст. Ожидаемый вывод — пять «✓» и «Моменты сошлись: 5 из 5, строк 11». Негативный
контроль: подменить слово в любой строке манифеста — инструмент краснеет с номером строки; вернуть.

Если контентный PR сдвинул расшифровку, инструмент покраснеет — это не повод ослаблять его, а повод
снять координаты заново: переиграть сид, найти те же моменты, обновить `pikabu-moments.json` и этот
файл.
