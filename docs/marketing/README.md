# Анонс-материалы (#1238)

Пакет для анонса на Пикабу. Публикует оператор — агент материалы готовит, но аккаунты не заводит и
посты не выкладывает. Публикация ждёт запуска Telegram Mini App (#1237): до этого в тексте стоят
плейсхолдеры ссылок.

| Файл | Что это |
|---|---|
| [pikabu-post.md](pikabu-post.md) | черновик поста: три заголовка, теги, текст, где стоят кадры |
| [pikabu-cut.md](pikabu-cut.md) | сценарий нарезки: пять моментов с координатами (сид + строки расшифровки) |
| [pikabu-publication.md](pikabu-publication.md) | паспорт публикации: хаб, окна, правила Пикабу, чек-лист, риски, метрика |
| [pikabu-moments.json](pikabu-moments.json) | координаты моментов в машиночитаемом виде — вход для проверки |
| [pikabu-preview.html](pikabu-preview.html) | превью поста так, как он будет выглядеть с кадрами |

## Как проверяются координаты

Все кадры взяты из одной партии — сид 296117, 300 ходов (плейтест-раунд 113,
`docs/PLAYTEST_ISSUES.md`). Строки в [pikabu-cut.md](pikabu-cut.md) — не пересказ: это адреса в
расшифровке.

```sh
node scripts/marketing-moments.mjs
```

Инструмент переигрывает партию ботом и сверяет каждый момент: номер строки и её текст. Пять «✓» и
«Моменты сошлись: 5 из 5, строк 11» — сценарий подтверждён. Испорченная строка в манифесте — красный
прогон с номером строки.

Проверка идёт **руками, а не в CI**: расшифровка сида сдвигается от каждого контентного PR, и сторож
на неё был бы красным не по делу. Поэтому в CI живёт только тест самого инструмента
(`src/tools/marketing-moments.test.ts`), а координаты переснимают, когда меняется контент.

## Что осталось оператору

- вычитать текст (задача требует вычитку до закрытия #1238) и выбрать заголовок;
- после #1237 заменить плейсхолдеры Telegram-ссылки на боевые;
- снять пять кадров по сценарию и проверить хаб/сообщество в интерфейсе (см. памятку).
