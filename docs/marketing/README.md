# Маркетинговые материалы

Актуализировано 29.10.2026. Текущий запуск — **Telegram и веб**. VK и Яндекс отложены по решению
оператора; их подготовка не блокирует анонс. Название на всех площадках — «Алик, где деньги?».

Основа подачи: «Игра в переписку с подрядчиком, который должен тебе денег».
Полное описание бота утверждено в [telegram-bot.md](telegram-bot.md). Остальные обновлённые тексты —
черновики для вычитки оператором. Агент готовит пакет; публикации, переписка с администраторами и
настройки аккаунтов остаются оператору.

## Проверка сцен

```sh
node scripts/marketing-moments.mjs
```

Команда переигрывает партию из манифеста и проверяет **непустой** набор строк. Успешная сверка
подтверждает существование реплик на этой версии игры, но не качество кадра и не повторяемость
сцены в любой партии. После контентных изменений перед съёмкой выполнить команду снова.
Координаты намеренно проверяются вручную, не в CI; тест инструмента —
`src/tools/marketing-moments.test.ts`.

## Перед первым размещением

- Вычитать анонсы и выбрать основную подачу.
- Снять три кадра и короткое видео настоящей игры; не использовать HTML-макет как скриншот.
- Проверить вход с нового аккаунта Telegram и веб без сохранения на телефоне.
- Проверить получение событий в кабинете аналитики, отдельно для Telegram и веб.
- Выбрать первые сообщества и согласовать размещения; Пикабу не включать без ответа модерации.

Локальные варианты аватара и обложки в `assets/` пока не включены в Git. Их наличие на машине
не означает, что графика утверждена, опубликована или доступна из клона репозитория.
