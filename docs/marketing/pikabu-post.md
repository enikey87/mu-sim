## Заголовки на выбор

- «Алик, где деньги?» — игра про подрядчика, который полгода не платит.
- Сделал игру про человека, у которого на всё есть отмазка. Кроме оплаты.

## Редакторские решения

- Полгода — срок ожидания денег героем, не дата завершения разработки.
- Показываем выбор и реакцию: читатель должен понять, что сам участвует в переписке.
- Не раскрываем суммы финальных выплат, концовки и большую финальную отмазку.
- Не обещаем число дней, концовок или комбинаций; они не нужны для первого знакомства.
- Не обещаем ответ нейросети на любой текст. Свободный ввод поддерживает игровые намерения,
  а не произвольную беседу обо всём.
- Просьбу о донате не добавляем. Добровольная поддержка внутри игры не нужна для старта партии.
- История разработки агентами — отдельный материал для технической аудитории. Если о ней
  спрашивают, отвечать прямо, в соответствии с README проекта.

Три момента и порядок кадров — [pikabu-cut.md](pikabu-cut.md). Фразы в квадратных скобках —
места вставки настоящих материалов, перед размещением их убрать. Теги и ограничения выбранного
сообщества проверить после согласования; старый список тегов не считать обязательным.
