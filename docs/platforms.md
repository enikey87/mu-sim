# Яндекс Игры и VK (мини-приложение)

Веб-сборка GitHub Pages не меняется: `npm run build` без `VITE_PLATFORM`. Платформенные сборки — тот же клиент с другим адаптером (`src/platform/`). Скрипты в `package.json` не добавлялись.

## Сборка

```sh
npm run typecheck
npx vite build                         # веб, dist/
npx vite build --mode yandex --outDir dist-yandex
npx vite build --mode vk --outDir dist-vk
```

`--mode` читает `.env.yandex` / `.env.vk` (`VITE_PLATFORM`). В веб-бандле нет запроса к `/sdk.js` и нет пакета `@vkontakte/vk-bridge`: ветки вырезаются по константе режима.

Архив для Консоли Яндекса — содержимое `dist-yandex`, `index.html` в корне ZIP. В `index.html` скрипт SDK не вшит: игра грузит `/sdk.js` сама, только в режиме `yandex`.

## Что вызывает адаптер

| | web | yandex | vk |
|---|---|---|---|
| Старт | ничего | `YaGames.init()` | `VKWebAppInit` |
| После первого кадра | ничего | `LoadingAPI.ready()` | ничего |
| Игрок может ходить / оверлей или вкладка скрыта | ничего | `GameplayAPI.start()` / `stop()` | ничего |
| Карточка «займи 50» со ссылкой | есть | нет | нет |

Отказ или зависание SDK (дольше 8 с) не останавливает партию: игра открывается без витринных вызовов. Ссылка на DonationAlerts при этом не возвращается — режим сборки уже не web.

Отладка загрузчика Яндекса: к адресу игры добавить `debug-mode=16`. В левом нижнем углу `W` — ждёт, `IT` — инициализация верна, `IF` — старый лоадер.

## Чек-лист перед загрузкой в Консоль Яндекса

- ZIP, `index.html` в корне, игра открывается в iframe на домене Яндекса.
- В архиве нет абсолютного `https://yandex.ru/games/sdk/v2`: только динамический `/sdk.js` после `init`.
- `LoadingAPI.ready()` — после первого кадра, не до него.
- `GameplayAPI.start()` когда игрок может действовать; `stop()` на интро, досье, экране концовки, севшем телефоне и при уходе с вкладки.
- Нет внешней платёжной ссылки (карточка «займи 50»).
- Реклама, облачные сейвы, платежи и лидерборды — не в этой сборке.

## VK

Путь — мини-приложение (dev.vk.com), не витрина VK Play. Обязательный вызов на старте — `VKWebAppInit` через `@vkontakte/vk-bridge`. Хранилище, реклама и платежи VK — после этого шага.

## Чего сборка не делает

CI по-прежнему собирает только веб. Загрузка в консоли — вручную, этими командами.
