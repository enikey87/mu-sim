# Алик, где деньги? 🐄

**▶ Играть: https://enikey87.github.io/mu-sim/**

Браузерная юмор-игра: SMS-переписка с генподрядчиком Аликом Воздухонесяном. Ты сделал работу полгода назад, вежливо просишь свои деньги — а Алик каждый раз отвечает новой абсурдной отмазкой. Иногда на фоне кто-то говорит «Мууууу».

- отмазки без повторов: тысячи комбинаций + 100 легендарных
- ветвящиеся сцены: встреча в кафе, номер карты, бартер бараном, акт взаимозачёта, смертный одр…
- сериалы: баран Борис, деньги в фундаменте, свадьба Самвела, побег «Нивы», Нуне, Грант, Размик на кране, инспектор Рубик, похороны Алика, Гарик в фундаменте…
- Алик живёт сам: пишет первым, спит ночью, удаляет сообщения, опечатывается, шлёт стикеры и голосовые
- можно выбрать готовую реплику или написать свою; игра отличает просьбу, угрозу, запугивание, извинение, «муу» и другие типы ввода — без подписи категории, но с разным откликом телефона (тряска, затемнение, зелёный импульс, корова)
- кричишь — растёт ссора: родня пишет в личку, мама звонит, Алик блокирует и пишет с телефона барана, семейный суд в групповом чате, вежливость-убийца, вендетта
- третий акт «День выплаты»: все линии партии сходятся в один день, а Алик выдаёт великую отмазку, собранную из твоих же событий (её можно скопировать)
- Алик помнит партию: хаш, на который ты ездил, суд, пойманную ложь, свадьбу, на которой ты был тамадой, — и вспоминает это к месту (реплики с условиями и приоритетом, как в Hades)
- Алик помнит: третья грубость, третья угроза судом, толстый журнал обещаний — у всего свой ответ
- Алик путается во вранье: деньги то в банке с огурцами, то в Дубае — **поймай его на лжи**
- у сериалов разные финалы — по тому, как ты играл: Борис-прораб платит тебе 500 ₽, Самвел выдаёт за тебя племянницу, Алик завещает тебе свой кредит; из финалов складываются **6 концовок игры**
- в день срока обещания Алик пишет сам; упомянутые персонажи вклиниваются в разговор; свадьба, болезнь Бориса и «смерть Алика» окрашивают дни
- чат не уезжает из‑под пальца: пока читаешь историю — кнопка «новые сообщения»; свои реплики снова тянут вниз

## Разработка

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest: движок, контент, сценарии правил, симуляция, интерфейс
npx playwright install chromium  # один раз: браузер для UI-тестов
npm run test:e2e   # Playwright: сценарии в desktop и mobile Chromium против прод-сборки
                   # (собирает dist и подаёт его через `vite preview` на :4173; dev — на :5173)
npm run typecheck
npm run lint       # ESLint (в CI)
npm run format     # Prettier --write (опционально; стиль плотный, массовый прогон отдельно)
npm run build      # сборка в dist/
npm run rules:report  # покрытие правил: что срабатывает, что никогда, где побеждает общий ответ
npm run rules:stable  # список редких правил не протух: покрытая всеми выборками запись больше не редкая
npm run test:rules    # движок правил с покрытием (порог 100%)
PLAYTEST_OUT=pt PLAYTEST_SEEDS=1-8 npm run playtest  # партии ботом: переписка с вариантами и запись действий (seed воспроизводит партию)
```

Параметры адреса для проверки: `?fast` — паузы в ~30 раз короче, `?hour=3` — подменить реальный час, `?away=90` — «игрока не было 90 минут», `?debug` — панель «какое правило выбрано и почему» и память Алика.

`typescript` в deps — API 6.x для ESLint (`typescript-eslint` пока не умеет TS 7); компиляция — `typescript-7` (`npm run typecheck`).

Досье (📋): Esc закрывает. Концовка Дня выплаты: «Скопировать» → тост «Скопировано».

## Как устроено

Vite + React + TypeScript. Решения «что ответить», «что предложить игроку» и «что сделать Алику» принимает **система правил** по мотивам доклада Valve об озвучке Left 4 Dead: на событие собираются факты о мире, и срабатывает самое специфичное подходящее правило. Частный случай — отдельное правило с дополнительным условием, общий код не трогается.

Звук: SMS-писк, «Мууу», голосовые через Web Speech API (фразы Алика / застолье). Фонового эмбиента нет.

```
src/
  engine/   движок: rules/ (изолированный модуль, покрытие 100%), input.ts (классификация ручного ввода),
            game.ts (ход, сцены, сериалы, «живость», отклик на ввод), state.ts, deck.ts + uniq.ts,
            time.ts, clock.ts, audio.ts, typo.ts
  content/  тексты и данные: excuses.ts, scenes.ts, arcs.ts, finales.ts, legends.ts, lies.ts,
            memory.ts, quests.ts, payday.ts, rude.ts, life.ts, achievements.ts,
            rules/ — turn, replies, choices, world, finales, rude, court, payday
  ui/       React-телефон: чат со следованием ленты, досье, концовки, debug-панель
  test/     помощники и большая симуляция
  tools/    бот для плейтестов и отчёт по правилам
```

Добавить реакцию Алика — одно правило в `src/content/rules/`:

```ts
{
  name: 'Says_condole_ctxrevived',
  event: 'PlayerSays',
  when: [eq('intent', 'condole'), is('ctx.revived')],   // специфичнее общего «соболезную»
  respond: async ({ game }) => { await game.say(['Не соболезнуй, брат, он уже встал.']) },
}
```
