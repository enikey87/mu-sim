# Алик, где деньги? 🐄

**▶ Играть: https://enikey87.github.io/mu-sim/**

Браузерная юмор-игра: SMS-переписка с генподрядчиком Аликом Воздухонесяном. Ты сделал работу полгода назад, вежливо просишь свои деньги — а Алик каждый раз отвечает новой абсурдной отмазкой. Иногда на фоне кто-то говорит «Мууууу».

- отмазки без повторов: тысячи комбинаций + 100 легендарных
- ветвящиеся сцены: встреча в кафе, номер карты, бартер бараном, акт взаимозачёта, смертный одр…
- сериалы: баран Борис, роман бетона и крана, похороны Алика, Гарик в фундаменте
- Алик живёт сам: пишет первым, спит ночью, удаляет сообщения, опечатывается, шлёт стикеры
- кричишь — растёт ссора: родня пишет в личку, мама звонит, Алик блокирует и пишет с телефона барана, семейный суд в групповом чате, вежливость-убийца, вендетта
- Алик помнит партию: хаш, на который ты ездил, суд, пойманную ложь, свадьбу, на которой ты был тамадой, — и вспоминает это к месту (реплики с условиями и приоритетом, как в Hades)
- Алик помнит: третья грубость, третья угроза судом, толстый журнал обещаний — у всего свой ответ
- Алик путается во вранье: деньги то в банке с огурцами, то в Дубае — **поймай его на лжи**
- у сериалов разные финалы — по тому, как ты играл: Борис-прораб платит тебе 500 ₽, Самвел выдаёт за тебя племянницу, Алик завещает тебе свой кредит; из финалов складываются **6 концовок игры**
- в день срока обещания Алик пишет сам; упомянутые персонажи вклиниваются в разговор; свадьба, болезнь Бориса и «смерть Алика» окрашивают дни

## Разработка

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest: движок, контент, сценарии правил, симуляция, интерфейс
npm run typecheck
npm run build      # сборка в dist/
npm run rules:report  # покрытие правил: что срабатывает, что никогда, где побеждает общий ответ
npm run test:rules    # движок правил с покрытием (порог 100%)
```

Параметры адреса для проверки: `?fast` — паузы в ~30 раз короче, `?hour=3` — подменить реальный час, `?away=90` — «игрока не было 90 минут», `?debug` — панель «какое правило выбрано и почему» и память Алика.

## Как устроено

Vite + React + TypeScript. Решения «что ответить», «что предложить игроку» и «что сделать Алику» принимает **система правил** по мотивам доклада Valve об озвучке Left 4 Dead: на событие собираются факты о мире, и срабатывает самое специфичное подходящее правило. Частный случай — отдельное правило с дополнительным условием, общий код не трогается.

```
src/
  engine/   движок: rules/ (система правил — изолированный модуль, покрытие 100%), game.ts (ход, сцены, сериалы, «живость»),
            state.ts, deck.ts + uniq.ts (без повторов), time.ts, clock.ts, audio.ts, typo.ts
  content/  тексты и данные: excuses.ts (генератор), scenes.ts, arcs.ts, finales.ts (финалы и концовки), life.ts, achievements.ts,
            rules/ — все правила: turn.ts, replies.ts, choices.ts, world.ts, finales.ts
  ui/       React-компоненты телефона
  test/     помощники и большая симуляция
```

Добавить реакцию Алика — одно правило в `src/content/rules/`:

```ts
{
  name: 'Says_condole_ctxrevived',
  event: 'PlayerSays',
  when: [eq('intent', 'condole'), is('ctx.revived')],   // специфичнее общего «соболезную»
  respond: async ({ game }) => { await game.say(['Не соболезнуй, брат, он уже встал.']) },
}
```
