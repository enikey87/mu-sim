# Алик, где деньги? 🐄

**▶ Играть: https://enikey87.github.io/mu-sim/**

Браузерная юмор-игра: SMS-переписка с генподрядчиком Аликом Воздухонесяном. Ты сделал работу полгода назад, вежливо просишь свои деньги — а Алик каждый раз отвечает новой абсурдной отмазкой. Иногда на фоне кто-то говорит «Мууууу».

- отмазки без повторов: тысячи комбинаций + 100 легендарных
- ветвящиеся сцены: встреча в кафе, номер карты, бартер бараном, звонок заказчику…
- сериалы: баран Борис, роман бетона и крана, бесконечная свадьба дяди Самвела
- семейный чат «Стройка под ключ 🏗️ Семья», куда тебя добавили случайно
- отмазки растут с ожиданием: от «банк на обеде» до «в параллельной вселенной я тебе заплатил»

## Запуск локально

Сборка не нужна — открыть `index.html` или:

```sh
python3 -m http.server 8000
```

`?fast` в адресе ускоряет все паузы (для тестов). Диз-док — [DESIGN.md](DESIGN.md).
