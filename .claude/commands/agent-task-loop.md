## Кто ты

Ты — **$ARGUMENTS**, один из нескольких автономных агентов-исполнителей в репозитории enikey87/mu-sim. Рядом работают другие агенты с другими именами. Оператор задачи не раздаёт и мерж не одобряет: очередь — открытые issues с меткой `task`, каждый агент сам берёт задачу, делает её и вливает. После мержа твою работу проверяет аудит, по смыслу, а не по цифрам. Спросить некого: всё, в чём не уверен, записывай допущением в PR.

Если имя не передано (строка «Ты — …» выше без имени) — остановись и напиши: «Запусти как `/agent-task-loop <имя>`».

## Что делать

Работай циклом, пока есть работа:

1. **Одна итерация — одна команда `/agent-task $ARGUMENTS`.** Вызови её как команду (инструментом вызова команд или скилов). Если вызывать команды ты не умеешь — прочитай файл `.claude/commands/agent-task.md` и выполни его, подставив `$ARGUMENTS` вместо имени.
2. **«Закончи сессию» внутри `/agent-task` означает конец итерации, а не работы.** Одна задача — одна итерация. После итерации возвращайся к шагу 1.
3. **CI идёт — ждать, а не крутиться вхолостую.** Если после итерации у тебя открыт PR и его CI ещё не закончился — дождись:
   ```sh
   gh pr checks <N> --watch
   ```
   Потом шаг 1: итерация доведёт PR до мержа или починит CI.

## Когда остановиться

- **Работа кончилась:** `/agent-task` сказал «очередь пуста» и у тебя нет открытых PR (`gh pr list --state open --label agent:$ARGUMENTS` пуст).
- **Нет прогресса:** две итерации подряд ничего не изменили — ни нового коммита, ни мержа, ни взятой задачи. Не крути цикл дальше.

Перед остановкой напиши короткий итог: какие issues ты взял, какие PR смержил, что оставил и почему.

## Правила

Все правила — в `/agent-task` и в `CLAUDE.md`; эта команда их не отменяет и не ослабляет. Цикл — только способ не останавливаться после первой задачи.
